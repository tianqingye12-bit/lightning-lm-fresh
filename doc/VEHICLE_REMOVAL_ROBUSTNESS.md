# 视觉辅助车辆去除：边界修复与空间查询优化

本次改动针对 `scripts/clean_map_vehicles.py` 的离线语义地图清理流程。
视觉仍用于车辆分割与地图清理，不参与 SLAM 位姿估计。

- 使用一次构建的 `cKDTree` 查询附近体素，替代每张图像对整张地图的范围扫描。
  查询采用无穷范数，保持原有立方体候选区域；精确边界上的点也会被纳入候选。
  索引会增加内存和初始化开销，实际速度需用目标地图评估。
- 用三维整数坐标替代固定位宽拼接键，避免大坐标导致体素混淆或错误连通。
- 精确匹配的关键帧时间戳可直接返回位姿，支持单关键帧；四元数归一化，
  重复时间戳、零四元数和非有限轨迹会明确报错。
- 无效 XYZ 点不再计入体素中心，输出保留这些原始记录；全无效地图明确报错。
- 支持空连通分量及全部处于地面保护层的地图。
- PCD 缺少 DATA 头时明确报错，避免无限读取；深度图尺寸不匹配时提示先与彩色图对齐。

## 验证

安装项目已有依赖中的 numpy、scipy、OpenCV、PyYAML 后运行：

```bash
python3 -m unittest discover -s tests -p 'test_vehicle_removal.py' -v
```

回归用例覆盖投影遮挡、深度图尺寸、空间候选集、体素碰撞、连通分量、
位姿时间边界、损坏 PCD、无效点以及全地面地图的读写流程。
测试中的完整读写流程替换了 YOLO 模型与 bag 读取，不需要下载权重或启动 ROS。

尚未使用实际 ROS bag、相机标定和 GPU 验证，不能据此给出识别精度或端到端提速结论。
